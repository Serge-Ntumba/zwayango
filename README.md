# Zwayango Coming Soon Page

Static coming-soon landing page for Zwayango.

## Files Published to GitHub Pages

The GitHub Pages workflow deploys only:

- `index.html`
- `styles.css`
- `assets/`

Design notes and reference images can stay in this repository without being published by the Pages artifact.

## Publish Setup

1. Create a GitHub repository.
2. Push this project to the `main` branch.
3. In GitHub, open `Settings -> Pages`.
4. Set `Build and deployment` to `GitHub Actions`.
5. Push to `main`, or run the `Deploy static site to GitHub Pages` workflow manually.

After deployment, GitHub shows the live Pages URL in the workflow summary and in `Settings -> Pages`.
